# Eric Nortmann's Portfolio

## Project Option
Website

## Project Description
I created an interactive, outer space themed portfolio website to showcase my
background in Game Development and Software development. Visitors are able to
explore the different sections, like an “About me” biography, a detailed gallery of my
projects where a user can click on one of the projects to learn more about it, my work
experience, and a breakdown of my skills.
What makes this project interesting is how it shows the personal aspect about me, what
I've built, and my career aspirations into one singular space page. After recruiters clear
my resume, they can see more personal things about me in my website.
To build this, I used HTML to structure the portfolios content and ensure the layout is
organized. With CSS, I styled the theme of my portfolio and bring the outer space
purple and black aesthetic to life. Then I used javascript to add dynamic changes to
the environment. I also programmed shooting stars that go across the background at
random intervals, as well as a navigation bar that hides when the users are at the top of
the page to show the clean introductory screen.

## Theme Interpretation
My website will use outer space by having an outer space background with normal stars
in the background. I will also have shooting stars every couple of seconds using
javascript.

## Intended User or Player
The intended audience for my project is recruiters from companies who are interested in
my work, or just for people who happen to come by my website!

## User or Player Goal
The user should be able to learn more about me, and look at the things I have worked
on or what I work with.

## Main Features
The major content sections are the intro screen with the stars and my name, the
about me section where it tells the users what I do, the projects section where it
shows all the project I have done, the experience section that shows my job
experience, and the skills section to show what skills I have. I also have separate
pages for each project to explain what it is and what I have done on it.

## JavaScript Features
The javascript interactions I have is that every couple of seconds a shooting
star will appear. I also made it so that the navigation bars are hidden when your on
top of the screen so it can give the intro scene a clean look. I also added a cursor tail so a white line follows
your cursor around to represent a star. I also added functionality to the arrow in my intro screen and mobile responsiveness.

## Responsive Design
My project adapts to a smaller screen by making the text a lot smaller, and by
stacking the projects vertically instead of horizontally. I also made the experience
cards be a lot bigger in length then in width so it can fit on phone screens.

## User Testing
Overall, it seems like peer testers easily understood the portfolio's purpose and liked the clean layout and the outer space theme. 
They said that the project cards and badges did good at showing off my skills and background. The responsive design was also highlighted, 
the testers confirmed that the project grid transitioned into a vertical layout on phone screens without the text clipping off the screen.

The testers did say there was some confusion when first loading into my page. The initial navigation arrow on my website was unresponsive and 
had no functionality, leaving users unsure of where to go on the website. A big issue was the sticky navigation bar, which overlapped section 
headers depending on where you were scrolling in on the website, making it look crowded visually.

While the basic links and project pages functioned correctly, users suggested improvements for interaction and responsiveness. 
A common request among the two replies was to improve the mobile navigation by implementing a hamburger menu rather than relying on the 
stacked layout. Testers also provided great ideas for some JavaScript interactions, specifically recommending a project filter to easily 
sort through my different skills, as well as adding a cool dynamic hover effect to the project cards to simulate floating in space.

## Revisions
Some revisions I made were adding functioanlity and text to the arrow on my intro screen, fixing the nav bar overlapping title headings,
mobile navigation taking up to much space by adding a hamburger menu, the project cards lacking depth and need better visuals by adding a 
cool sway when hovered, and then adding a white tail behind the cursor.
